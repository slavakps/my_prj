# Обработка банковских операций

Проект предоставляет функции для работы с банковскими операциями:
- Фильтрация и сортировка операций
- Маскирование номеров карт и счетов
- Инструменты для эффективной работы с большими объемами данных транзакций
- Все функции протестированы отдельно

## Реализованный функционал

Добавлен универсальный декоратор `@log` для логирования выполнения функций.

Добавлен конвертер финансовых транзакций

Реализована функция для считывания финансовых операций из CSV.

Реализована функция для считывания финансовых операций из Excel.
